# dailyfocusr-site

The public pages for the Daily Focusr app, served with GitHub Pages:

- `index.html`: what the app is
- `privacy.html`: the privacy policy linked from the store listings
- `delete-account.html`: how to delete an account, which Google Play requires as a web page

Plain HTML, no build step. The promises on these pages are kept by the app and backend; change them
together.
